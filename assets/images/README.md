# Logo Assets

## Add Your BlankBlitz Logo Here

1. Save your logo image as: `logo.png`
2. Place it in this folder: `assets/images/logo.png`
3. The app will automatically display it!

### Recommended Size
- **1024x1024 pixels** (square)
- **PNG format** with transparent background
- High quality for all screen sizes
