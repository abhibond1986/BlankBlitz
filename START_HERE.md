## 🚀 Get Started in 3 Steps

### Step 1: Set Up Database (2 minutes)
1. Open: https://app.supabase.com/project/qockwvfaqttyucuymmzf/sql
2. Click "New Query"
3. Open `supabase_schema.sql` from your project
4. Copy & paste the entire file
5. Click "Run" (green play button)
6. ✅ Database created!

### Step 2: Enable Authentication (30 seconds)
1. Go to: https://app.supabase.com/project/qockwvfaqttyucuymmzf/auth/providers
2. Find "Email" provider
3. Toggle it ON
4. ✅ Auth enabled!

### Step 3: Run Your App! (30 seconds)
```bash
flutter pub get
flutter run -d chrome
```
✅ Your app is running!

## 🐛 If Something Goes Wrong

### Build Error?
```bash
flutter clean
flutter pub get
```

### Can't Connect to Supabase?
1. Check internet connection
2. Verify project is active
3. Check `lib/core/config/supabase_config.dart`

### Can't Login?
1. Make sure you ran `supabase_schema.sql`
2. Enable Email auth in Supabase
3. Check your credentials

### Need Help?
- Read `DEPLOYMENT_GUIDE.md`
- Check Flutter docs: https://flutter.dev
- Check Supabase docs: https://supabase.com/docs
